# M6 绘画、修复与基础滤镜

接续 M3 图层/锁/样式、M4 选区和 M5 可取消准备与显示预览。完整范围仍以 [PS 覆盖清单](photoshop-feature-coverage.md) 为准；基础实施顺序不删去 P1–P3。

## 首批：画笔、橡皮擦与蒙版绘制

- 点序列使用画布坐标、压力和明确的大小/硬度/不透明度/流量/间距；圆形软硬笔尖先建立稳定数值参考。按弧长放置笔触，输入采样率不能改变效果。
- 流量累积与整笔不透明度分开：多个笔尖采样先累积覆盖，再以整笔透明度限制强度；原图作为整笔不可变底图，预览重算不会重复叠加。
- 像素绘制在线性光和预乘 alpha 中混合，源工作 ICC/位深保持；零选区覆盖以原样本逐码回写，不能因为整块往返转换而改变受保护区域。橡皮擦只改变 alpha，保留隐藏 RGB。
- 像素与已有/显式新增的图层蒙版是不同目标。蒙版直接写 u16 覆盖，链接位置按现有 anchor 语义换算；不能误写图层像素。
- 同一笔只提交一条历史。候选挂在首个输入的文档/revision/epoch，Esc、切换文档、AI 接管、超时和预算失败拒绝迟到结果。
- 分块暂存和 COW，每个受影响块最多发布一次；所有临时覆盖/像素转换纳入共享预算，跨块软边、负坐标、8/16 位、锁及撤销/恢复有实际断言。
- 原生前景/背景色、工作 ICC 拾色器、压力输入与工具参数一并接入；不能只注册命令后标为完成。

## 后续顺序

1. 吸管、颜色面板、油漆桶（连续/容差/取样范围）、五类像素渐变与填充；延续明确的选区、alpha、权限和单条历史。
2. 仿制图章、修复/污点修复、减淡/加深/海绵；取样点、对齐和跨层取样边界明确，修复必须有实际纹理/边界匹配算法。
3. 高斯模糊、USM、确定性杂色和滤镜预览；保留跨块 halo、线性/工作空间定义、可取消预算与真实参数效果。
4. 继续完整清单的 PatchMatch、红眼、液化、画笔动态/预设/ABR、专业滤镜等。外部模型、用户照片和发布依赖各自保留授权与真实证据。
