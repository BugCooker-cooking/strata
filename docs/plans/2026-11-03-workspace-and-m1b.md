## 接续功能

- [x] 原生多文档标签，每个文档拥有独立引擎、选择、历史、脏状态；退出逐个确认未保存文档，重复打开定位已有标签。
- [x] 最近文件菜单：成功打开/保存后记录，去重并保留 10 项；用户选择后重新授予读取能力，列表本身不授予模型文件访问权限。
- [x] `file.place`：在活动层上方置入授权图片，保留原始尺寸，转换至当前工作 ICC/位深，一次撤销；预检/显示准备/提交均保持原有原子性。不可放进批事务。
- [x] 原生置入 → 属性修改 → 保存 → 最近重开 → 导出，与无界面逐样本验证一致。
- [x] `file.recent.list`：用户/测试源只读宿主历史；AI 只看本回合有效读取授权，隐藏路径且不授予能力；失效项不自动授权。
- [x] JPEG（质量 1–100、背景合成）/无损与有损 WebP（质量 1–100、透明 alpha、ICC、DPI）导出；PNG/TIFF/JPEG/WebP 的保留/sRGB/P3 目标色域；16→8 位显式量化确认，源文档不变。
- [x] 导出尺寸缩放：原生等比/独立宽高，8/16 位线性光、预乘 alpha 重采样，不改文档。
- [x] macOS HEIC：隔离 ImageIO 适配，打开/置入共用授权，主图、RGB ICC 和 EXIF 方向校正。
- [x] 新建文档预设/分辨率/背景参数；预设、DPI、色域与背景随工程往返。
- [x] 30 秒空闲恢复检查点、独立恢复副本、最近成功时间、启动/菜单恢复入口；恢复为未保存文档。
- [x] 跨文档 CPU 像素/缓存/暂存、GPU 资源预算与全局 LRU；源/历史块磁盘后备和校验；工程逐块读写。
- [x] 本机 50MP×30 固定种子独立随机 RGBA16 图层：24,000 个块不共享/不去重；256 MiB 像素预算下完成全量像素色域转换、撤销重做、恢复及保存重开，峰值 RSS 325.28 MiB。
- [x] 当前 Mac 8/16 位 24MP×20 独立图层的原生 CADisplayLink 三轮基准均通过，见 [原生验收](../research/2026-11-m1b-native-acceptance.md)。
- [x] 两份原生 24MP×20 文档的 GPU/缩略图压力、清理重建、样本不变和进程正常退出；GPU 峰值 480.17 MiB，画布释放后为 0。
- [ ] 最终精确源码归档和增量 CI；M0 的 P3 人工读数仍未补齐。标准 M1 Mac、macOS 14、跨屏和物理触控板继续明确为未验证设备门槛。
