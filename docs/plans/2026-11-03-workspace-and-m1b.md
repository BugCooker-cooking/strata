# 完整界面框架与 M1b 后续

2026-11-03：按用户要求，先将已确认的 v1 界面框架落实到原生应用，再继续功能计划。M1a 已完成，不改变其数据/权限边界。

## 界面框架

- [x] 统一标题栏、文档入口、工具选项、分组工具栏、Metal 画布、检查器/图层、AI 面板、状态栏。
- [x] 检查器与 AI 分隔线可调整，面板可收起；最小窗口 1280×720，浅/深/跟随系统主题使用集中令牌。
- [x] 属性/调整/历史切换；已有图层、文件、撤销和视图动作接入同一核心；未交付能力明确禁用。
- [x] 缩放、画布坐标、标尺/导航框由真实视图计算；图层显示有界、色彩管理的真实缩略图。
- [x] 操作权状态统一控制可用性；AI 默认未接入，运行/暂停显示真实控制状态；不保存密钥、不发送网络请求、不伪造执行记录。
- [x] 原生 UI 验收、键盘与最小窗口布局测试、Swift/Rust 回归和 Release。
- [ ] 当前提交的 Linux/macOS CI。

## 接续功能

- [x] 原生多文档标签，每个文档拥有独立引擎、选择、历史、脏状态；退出逐个确认未保存文档，重复打开定位已有标签。
- [x] 最近文件菜单：成功打开/保存后记录，去重并保留 10 项；用户选择后重新授予读取能力，列表本身不授予模型文件访问权限。
- [x] `file.place`：在活动层上方置入授权图片，保留原始尺寸，转换至当前工作 ICC/位深，一次撤销；预检/显示准备/提交均保持原有原子性。不可放进批事务。
- [x] 原生置入 → 属性修改 → 保存 → 最近重开 → 导出，与无界面逐样本验证一致。
- [ ] `file.recent.list` 的命令契约（当前只提供宿主菜单；模型可见范围需明确）。
- [ ] HEIC、JPEG/WebP 导出、尺寸/质量/目标色域参数与显式量化提示。
- [ ] 30 秒空闲恢复检查点、恢复副本与启动恢复入口。
- [ ] 全局 CPU/GPU/历史预算、磁盘后备、独立超内存工作集验收。

界面中的调整、选区、绘画、蒙版、文字及模型连接入口仍不可用，按后续里程碑实现。框架完成不代表完整 M1/M1b 完成。验证与限制见 [本轮实施记录](../research/2026-11-workspace-progress.md)。
