# 编辑功能的 AI 入口完整性验收

用户要求先完成完整编辑功能，再检查是否全部为 AI 预留了可由提示直接调用的入口。开发期同步接入，最后对完整清单逐项验收；当前不宣称全功能完成或 AI 全覆盖。

## 必须连接的路径

1. 完整 Photoshop 综合条目及其中的独立子动作 → 真实编辑实现。
2. 手工 UI 编辑动作 → 同一命令注册表与执行器，不能只提供私有按钮回调。
3. 命令 → 中英文标题/说明/检索别名、严格参数与返回 schema、权限/确认/资源获取、位深/选区/锁和历史语义。
4. 自然语言提示示例 → 可检索的操作关键词 → `describe_commands` → 合法 `invoke_command` 参数 → 真实结果及可撤销记录。

## 自动核对与实际验证

- 从实际注册表导出机器目录；命令必须存在真实执行分支，所有隔离示例实际执行，禁止未来占位命令进入 AI 目录。
- 建立功能与命令/参数变体/提示词示例的映射。组合条目必须覆盖全部子动作；单个通用命令下的不同调整/形状/模式也要分别列出。
- 校验映射引用的命令、参数变体和关键词可检索，`describe_commands` 返回 schema 与实际执行一致；权限、目标/revision 绑定、取消和历史通过相同宿主路径。
- 区分文档编辑操作、视图命令和纯宿主交互状态。宿主文件/剪贴板选择需明确可信宿主流程，AI 不应索取用户手写资源 token；需要区域/主体时先读取文档/图层并取得必要选区。
- 导出每条功能的实现状态、命令、提示、执行证据以及缺口清单。开发中允许显示待实现/待核对；最终验收须明确检查无遗漏，不能把“当前所有命令可调用”当作“所有功能都有入口”。
- 两种协议的模型端到端验收单独记录；仅使用已授权的仓库示例及服务，密钥留在设置/钥匙串。常规本机回归使用录制/确定性工具调用，不新增未经授权的外发或云端构建。

## 当前基础

画布拖线拉直接入同一 `image.straighten`，原生会话绑定文档/版本/控制 epoch/操作，AI 两点参数、严格 schema 与替换确认保持相同路径；真实拖线/缩放/回车/Esc 与一次撤销已有本机证据，见[交互记录](../research/2026-11-m7-straighten-gesture-progress.md)。

已有八个 meta-tools、动态 browse/search/describe/invoke 和统一注册表。基础滤镜新增三个实际入口，并增加对应中文操作关键词与参数示例；完整功能映射与最终全量审计仍待后续实施。

当前已建立 [90 个已实现/部分实现条目的映射](../research/ai-editing-entrypoints.json) 和 [265 综合条目的审计表](ai-editing-entrypoint-coverage.md)，并接入本机命令检查。提示检索/说明及滤镜、配置指定、整层像素变换、画布大小的真实 AI invoke/整轮撤销已通过合同回归；变换覆盖逐次替换确认与先读边界。当前真实目录为 128 命令、191参数示例。最终全量编辑实现与严格审计仍未完成，当前 11 个部分入口和全部待实现项保持开放。原生前景/背景色状态缺口已通过统一 paint.colors.* 工具状态命令补齐，工作 RGB/版本/控制权/非文档历史语义均有合同和单窗口证据；见[调色板记录](../research/2026-11-m7-paint-colors-progress.md)。

高反差保留的中英文发现/说明、严格 schema、精确替换确认、实际改码和整轮撤销已通过本机回放；原生使用同一滤镜参数/单槽预览。审批恢复后原生、强制真实 Metal、Release 与单窗口增量验收也已补齐；已有映射不代表完整 PS 或最终 AI 审计完成，见[本轮进展](../research/2026-11-m7-high-pass-progress.md)。

画布手柄产生的四角参数沿用真实 transform.apply，五种操作均有本机 AI 精确确认/实际改码/回合撤销。注册与提示现在明确轮廓草稿、Enter/Esc、恒等无历史及未支持类型；完整自由变换、连续像素反馈和最终逐功能审计继续保持开放，见[手柄进展](../research/2026-11-m7-transform-handles-progress.md)。

可编辑文字同步新增四个真实 type.* 命令：固定字体发现、创建、完整属性重编辑与可见源读取；点/段落/字族/对齐变体、双语提示、实际创建重编辑和回合撤销已接入。文字与全功能的最终审计仍保留未覆盖范围，见[文字进展](../research/2026-11-m7-editable-text-progress.md)。
