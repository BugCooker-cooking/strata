# M7 可编辑横排文字

接续 `bb07cc8`，2026-11-07。本机验证、两个编译任务和一个原生实例的约束保持；完整 PS 是持续范围。

## 当前增量边界

- 跨平台 Rust 文字排版及字形栅格，固定内置 OFL Noto Sans、Noto Serif、Noto Sans CJK SC。固定哈希/许可随库保存；字体 ID 与排版版本进入工程，不读取或向模型暴露系统字体路径。系统字体、任意字体导入和更多字种仍待后续。
- 真实点文字与段落文字，保留 Unicode 原文、字族、字号、工作 RGB/透明度、相对行距、像素字距、左/中/右/两端对齐与宽高。中文/CJK word-or-glyph 换行及双向布局，缺字明确拒绝，不用豆腐块或平台截图假装成功。
- 点文字的 x/y 是首行基线锚点；段落 x/y 是框左上角，溢出文字保留但字形裁在框内。颜色按文档8/16位量化，字形灰阶覆盖为8位再扩展u16，重叠按整数source-over；这是明确的栅格精度边界。
- LayerKind::Text 保存完整原文和样式；持久化的原位深分块是派生字形缓存，后续文字编辑由同一排版器重建。文字工程使用manifest7，无文字工程继续写manifest6。读取/撤销/恢复/重复图层保留可编辑定义。
- 现有蒙版、剪贴、混合/不透明度和样式共用合成器；深度与ICC转换同步定义颜色及缓存。删除裁剪保留永久局部支持，后续文字编辑不让被删字形在画板外重新长出。栅格化通过已有显式操作，一次撤销恢复文字定义。
- 一般文字几何尚未实现时明确拒绝整图方向/重采样，不静默只变缓存；综合图像几何和栅格化/文字属性条目按实际范围记录。

## 统一入口及原生编辑

`type.fonts` 发现固定字体，`type.create`/`type.update` 是实际创建/编辑实现，`type.inspect` 读取可见文字源；严格 schema、中英文说明、真实参数例子、锁/选区/资源/控制权和历史同步交付。无变化不写历史。原生文字面板的草稿绑定document/revision/活动层，核心提交前再核对，避免迟到面板改到新文档。

T工具提供点选基线或拖段落框后编辑；文字面板支持完整文本与属性应用，标准原生文本编辑器处理输入法/文本编辑撤销，文档一次应用一次历史。逐字即时画布更新、画布内插入光标/富文本、竖排、路径文字、变形及OpenType高级选项独立保持开放。

## 必要本机证据

固定字体哈希/许可、独立全角字宽/基线/行距/CJK行数及裁框；不同字族/对齐/字距、缺字/空白/长度/非有限输入、取消/资源。双位深/ICC、原文重编辑、蒙版/样式/栅格化、工程迁移/恢复/精确撤销、删除裁剪后重编辑、锁/祖先/AI接管与迟到草稿；真实AI发现/参数/调用/回合撤销，原生输入法/面板、必要真实Metal/Release与单窗口后退出。未执行的检查不得提前标为通过。
