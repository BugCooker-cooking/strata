# M5 调色预览与单次历史

当前显式应用的调色参数面板已经可用；本项补齐交互预览，仍需真实性能证据后才能关闭实时预览门槛。

## 事务边界

- 预览从稳定图层 ID、文档 ID、revision、控制 epoch 和可信用户请求开始。候选参数走相同严格命令校验，预览只替换显示场景，不修改文档、撤销、保存状态、恢复或 AI 上下文。
- 多次预览最终只提交最后明确应用的一组参数，一条历史；取消、面板离开、文档/图层切换、AI 接管或请求超时清除预览。过期工作不能覆盖新的预览或新文档。
- 保存/导出、其他内容编辑和新 AI 回合必须先结束或撤销当前显示预览，不允许把未应用的参数当成文档事实。

## 原生调度

- 主线程只登记参数、递增预览序号和发出取消信号。短暂合并输入后后台准备场景，始终只有一个计算任务；中途输入更新撤销旧序号，保留最新参数继续计算。
- 不调用文档 dispatch 来实现逐次预览；最终应用才提交核心命令。颜色、曲线、通道、局部阴影/高光共用预览机制。
- 保留一份已提交显示场景供取消恢复；恢复不应再次计算大型调色。相机状态按当前画布保留。
- 编辑中的控件保持可用，显示进度/取消状态；绘制、读数和停止不能阻塞在准备锁上。错误不隐藏，取消不弹模态错误。

## 优化与验证

- 先用 CPU 作为像素参考和完整后备路径，记录冷启动、连续参数更新、停止/恢复和预算峰值。
- 点调色可用 GPU 参数或经过误差验证的有界颜色查找加速；必须使用真实工作 ICC，处理预乘 alpha、蒙版、扩展值和采样范围，不能以工作空间名称猜测配置。超出可证明范围保留 CPU 路径。
- 局部调色重用未改变的前缀/邻域亮度估计；参数指纹明确区分局部估计输入、核半径与最终强度。
- 检查预览前后文档样本、工程序列化、dirty/history/recovery 均不变；最终应用/取消/过期/低预算有真实断言。
- 固定 24MP 原生连续预览的延迟、帧率和取消时间分别记录。现有完整 CPU 导出耗时不能替代此项。
