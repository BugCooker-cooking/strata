# M3 图层系统补全

2026-11-05，按剩余开发计划接续。M2b 已实现局部修图并有两模型实测；十张固定质量集/完整原生性能和发布设备门槛继续独立追踪。

## 顺序与共享接口

1. **混合与锁**：补齐 27 模式的线性 Display P3 数学定义，Dissolve 用稳定像素坐标/图层 ID 的确定性噪声；颜色标签、填充不透明度、四类锁在核心校验。像素合成标准样例与 8/16 位回归同步。
2. **层树**：稳定 ID + parent 关系、同级底到顶顺序；嵌套组采用隔离合成，变换移动子树；拒绝环、孤儿、过深、跨组非法排序。新工程 manifest 版本明确扩展。
3. **生成与合成**：纯色/渐变填充、色相饱和度调整、剪贴链、蒙版应用、已有类型栅格化；向下合并/合并可见/拼合/盖印均有源保留语义与渲染对照。
4. **像素编辑与系统剪贴板**：核心显式授权的复制载荷、选区清除/剪切、新建图层；宿主只适配系统格式，剪贴板写入不由文档撤销恢复。
5. **样式与面板**：投影、描边、外发光、颜色叠加、渐变叠加；分别在 8/16 位透明边缘标准图验收。全部已支持命令有人机入口、参数说明、隔离示例与保存/撤销。
