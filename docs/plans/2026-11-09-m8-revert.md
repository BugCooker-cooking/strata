# M8 恢复到上次保存

接续 `f0fdd43`。完整PS范围继续推进，此项补独立文件能力。

- 当前工程最后保存路径优先，未存工程的已打开图片使用原始来源；新建/仅恢复检查点文档没有来源，保存后才能恢复。普通导出不改变来源。
- `file.revert_status`只返回当前来源文件名/种类/dirty，不返回路径或能力，不读取任意文件。`file.revert`严格要求新读授权与明确discard_changes=true，仅接受当前绑定来源，复用file.open的解码、工程读入与渲染准备。
- 成功后重新读取当前磁盘内容，清空撤销/重做并标为干净；这是生命周期替换，不能通过Undo取回放弃的修改。不写原文件。坏/丢失/未授权/不同文件、准备渲染失败、取消或旧上下文不能覆盖当前真值。
- 原生菜单确认绑定起始文档/版本/来源；AI仍要宿主选文件/确认上下文与历史丢弃，独立严格schema、中英文提示和实际可执行例子。Save As在不增加revision时也改变来源，提交仍需拒绝旧候选。
- 核心/文件/恢复回归、AI真实回放、原生取消/应用与必要真实Metal/Release、一实例验收恢复后退出。最多两个编译任务，重型检查串行，仅本机。

原生确认把起始revision作为expected_revision传给核心，既检查确认到调用之间的变化，也检查prepare到commit之间的请求版本；UI异步刷新尚未更新时同样不能丢弃新的真值。
