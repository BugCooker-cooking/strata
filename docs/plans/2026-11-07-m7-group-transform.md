# M7 图层组自由变换

接续 `339df5c`，完整PS范围继续；只做本机验证。文字几何与参考线的物理手工验收仍待Mac解锁，当前零Strata/XCTest实例。

## 本增量

- 沿用transform.apply的components/affine/matrix/corners与整层范围；支持嵌套像素/可编辑文字/无样式组子树。所有子层含隐藏子层按同一画布几何变换，保留ID、父子/剪贴关系、透明度/混合、文字源和链接/停用蒙版，不隐式合并或栅格化。
- 预检全部类型、样式、祖先/子树锁、源与输出预算及投影视界后再做工作。填充/调整/活动样式的一般几何仍独立开放，遇到未定义类型原子拒绝，不能以丢失定义换取表面成功。
- 查询/手柄和返回边界只来自有效可见子树；隐藏子层不通过边界或返回值泄露，但仍被同一操作变换。原始源包围盒缓存仅由可信宿主持有，不成为模型参数。
- 整数平移只移动子树位置，保留所有像素/蒙版块版本；恒等无历史。非平移逐层调用既有同一像素/文字几何内核，组蒙版同步重采样，重绑定锚点，不再隐式重复子层平移。一般变换的组位置表示变换后可见内容逻辑原点。
- 空层/子组在整组操作中保留并变换位置/蒙版；整个组无可见有限内容时明确拒绝。选区内像素范围继续仅允许像素层，组需明确栅格化后使用该范围。
- 有界源扫描、累计64M目标像素/蒙版访问、取消、共享资源及原文档一次历史/精确撤销。已有工程结构不需增加新层类型或新占位命令。
