# Strata v1 剩余开发执行计划

2026-11-04。发起人要求继续全部剩余开发；执行范围从已闭环的 M0/M1、工作区与 M1b 扩展为路线图的 M2a–M8。沿用既定 P0 与发布门槛，不把实现、回放、真实模型和外部设备验收混为一项。

## 顺序与接口

1. **M2a**：独立 `strata-ai`，注册表派生目录与八个元工具；可移植 Agent 状态机、提供方编解码与流式解析；宿主执行命令与原生权限，钥匙串、连接测试、聊天与回合历史。默认先问我，停止/超时使迟到结果失效。
2. **M2b**：分块选区/蒙版、曝光调整、持久化/撤销/渲染；主体模型的许可、校验、推理与手工修正；固定评测配置后运行真实模型任务。
3. **M3**：图层树、混合/锁定/剪贴/填充/样式/合并及剪贴板；冻结供后续使用的共享接口。
4. **M4/M5/M6/M7**：依次补选区、调色、绘画/修复/滤镜、变换/文字/视图/色彩。每项同时交付注册命令、手工入口、像素/往返/撤销验证。
5. **M8**：偏好、恢复管理、中英文、无障碍、性能与完整 AI 回归、文档和发布包。外部发布按用户授权执行。

所有阶段由当前主代理负责；沿用当前干净 checkout。逐项验收继续以 [P0 矩阵](2026-11-02-p0-acceptance-matrix.md) 和 [总路线图](2026-11-02-strata-v1-roadmap.md) 为准。

## M2a 实施检查点

- [x] 目录浏览/搜索/说明与八个工具的严格参数和有界输出。
- [x] `ToolHost` 与 Agent 状态机；请求 ID、重复工具调用、暂停/恢复、编辑范围批准、文件与外发能力隔离。
- [x] Anthropic/OpenAI 兼容适配；SSE 分片、多工具、token、完整性/截断错误；本地服务仅限回环地址，默认远程 HTTPS、禁止带凭据重定向。用户提供的远程 HTTP 兼容接口通过独立明文选项和上下文提示支持。
- [x] macOS 钥匙串与配置、连接及工具/视觉探测、实时文本与步骤、停止/提问/批准、文档对话存储。
- [ ] 回放五项接口任务及停止/超时/重复/越权/外发/暂停编辑测试；Linux 可移植性与原生构建。首轮本机通过，最终增量与远程 CI 另记。
- [ ] 两类真实模型验证。用户已确认可提供 Anthropic 与 OpenAI 兼容服务；密钥通过本机设置录入，不写仓库或日志。
