# M7 原始上下文绑定的画布自由变换手柄

2026-11-07，接续 `3a2dec1`，只做本机检查。完整 PS 仍为目标，本页记录当前可执行增量。

## 实际交互

- `⌘T`、工具栏或变换面板进入。整个像素层读取含隐藏 RGB/画板外内容的原始边界；选区模式读取原始有限选区边界。新图层、版本、文档、控制权或工具变化取消草稿。
- 原始矩形到最终四角始终使用同一 `transform.apply`；不在 Swift 中采样、栅格化或重新定义选区合成。框内平移，八个缩放手柄，独立旋转圆点，斜切/扭曲/透视模式，方向键微移。
- Shift 保持缩放比例、约束平移/扭曲方向、15°旋转；Option 围绕中心缩放。透视模式用成对角点沿主要局部轴反向移动。缩放可翻转；退化、非有限、折叠/交叉草稿不能应用。
- 拖动只显示轮廓，像素在 Enter/应用后更新；Esc/取消无历史。这一增量不冒充连续重采样的图像预览；既有数值面板图像预览保留，后续继续补即时画布图像反馈。

## 核心和桥接

- 沿用裁剪/拉直的单一操作绑定 token、局部 WorkCancellation；原始请求固定 document/revision/session/control epoch、layer、scope，取消旧 token 不得撤销新草稿或 AI 工作。
- 边界扫描与变换准备在不可变编辑器副本上执行，脱离编辑器/渲染锁；边界读取额外限制 64M 源码访问，逐行取消。取消无需取得编辑器/渲染锁。
- 实际准备、锁/选区/蒙版/ICC/位深/预算/显示失败与一次历史仍走已有严格命令。恒等变换直接返回 `changed=false`，不增加历史/revision/dirty、不替换较新的当前层；相同四角在校验后归一成精确恒等矩阵。
- 原生和 AI 返回 schema 收紧，已有参数、提示、示例、权限与实际四角调用证据同步更新。生成/组/文字一般几何仍开放，不隐式栅格化。

## 必要验收

独立手柄数值、旋转/负缩放/Shift/Option、局部坐标/四角/无效输入；整层/软选区/跨块/负坐标/锁/蒙版/工程/撤销；上下文、操作/层/范围绑定，取消及新 AI 工作不被旧 token 取消，准备/显示失败安全；原生真实 pointer/Enter/Esc/缩放后手柄，必要 Metal/Release、一次一个窗口后退出。根据实际证据逐项更新，不提前标记完整自由变换或文字已完成。
