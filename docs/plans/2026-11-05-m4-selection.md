# M4 选区系统补全

2026-11-05，依赖 M2b 的单通道 u16 COW 遮罩与 M3 共享图层接口。完整范围继续以 [PS 覆盖跟踪](photoshop-feature-coverage.md) 为准。

## 顺序

1. 椭圆、多边形/套索及选区重新选择；软边 16 位覆盖和四类运算；手工交互提交一条历史。
2. 高斯羽化、扩展/收缩、平滑、边界；有限画板范围、跨块 halo、预算失败原子性与标准形状测试。
3. 魔棒（容差、连续、可见合成/当前层取样）、快速选择（局部图割分割）；种子/前景背景约束、取消与大图采样限制明确。
4. 独立遮罩仿射变换；反向映射、双线性覆盖、选区以外原始像素完全不变。
5. 主体模型管理补全：本机版本/许可/哈希信息、导入/替换已支持模型、下载状态/取消/缓存；困难多人样例与 CPU/Core ML 一致性报告。
6. 蚂蚁线、AI 处理区域/用户修正叠加、当前选区上下文；真实两模型任务与固定性能。

## 验收

- [ ] 每个入口同时提供命令、参数说明、无界面隔离示例、原生工具和保存/撤销。
- [ ] 像素参考涵盖空集、全图、负坐标、跨块、8/16 位和软边。
- [ ] 算法任务可停止，迟到候选被拒绝；内存配额/磁盘不足保持原文档。
- [ ] 新选区结构工程迁移与恢复往返；历史与暂停用户操作在 AI 恢复信息中一致。
- [ ] 固定真实模型任务和困难主体质量集、预算/帧率门槛保留真实结果。
