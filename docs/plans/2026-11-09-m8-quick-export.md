# M8 快速导出预设

接续 `008d64b`。优先收P0的“快速导出/导出为”缺口，不以此次增量代替完整Photoshop/最终AI闭环。

- 真正复用现有导出器、ICC/DPI、预乘线性重采样、16位量化与单次文件能力，不产生另一套编码路径。
- 注册严格中英文 `file.export_preset.get/set` 与 `file.quick_export`。预设保存格式、原尺寸或固定宽高、色域、JPEG背景、有损质量、WebP模式和明确量化选择；不保存路径、目录、资源token或覆盖权限。
- 应用共享、版本化、跨标签页读取即时生效。核心独立宿主可持有共享store，原生持久化仅限已验证选项；配置损坏不隐式写文件。同值规范化无版本增量，旧设置/导出候选不能覆盖新状态。
- Settings权限不进入文档历史/dirty/project，AI不论Direct或AskFirst都明确批准本次全局设置，且不借此取得普通编辑或文件写权限；快速导出仍走宿主选文件/覆盖确认。
- 原生设置与导出菜单用同一命令。预设设置保留任意合法AI背景色；原尺寸与固定尺寸可区分，量化是明确持久选项，文档原件不变。
- 核心独立编码/解码参考与精确状态保留、资源/过期/取消/CAS、AI发现/设置批准/独立文件能力、原生持久化/跨引擎/坏配置，必要Metal/Release/一个窗口后退出。本机最多两个编译任务，重型检查串行，云端保持禁用。

发布期间通过独立元数据计数固定预设版本，其他引擎仍可立即读取；此时变更设置明确返回忙碌，待导出结束重试。读锁不跨磁盘编码持有，以免等待写设置的其他标签页阻塞主线程读取。此并发条件有实际跨线程检查。
