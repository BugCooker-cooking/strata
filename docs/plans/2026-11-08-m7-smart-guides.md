# M7 图层间吸附与智能参考线

后续开发计划，接续当前正在验收的标尺单位/原点。未来功能尚未注册为完成项；用户要求完整PS与逐功能AI入口继续，不以此页为终止范围。

## 下一项实际能力

- 在既有layer.snap_position和view.presentation中显式选择其他可见图层边缘/中心作为吸附来源；原生V/数值入口共用同一核心解析。保留既有参考线/画板开关、确定性并列规则、整数坐标和小数残差，不改变默认关闭的自动吸附行为。
- 候选排除自身子树、包含目标的祖先、隐藏或隐藏祖先内容；组参考边界只合并可见子内容。原码含画板外源，文字空缓存复用保留字形；样式边缘与蒙版不能伪装成已支持的可见墨迹边界。
- 候选源扫描与目标扫描共用64M访问/资源预算；原生预览一次测量并固定候选边界，绑定文档state/版本、控制epoch、目标及视图版本。不能每次指针事件重复扫描整个工程，模型不能传入可信缓存。
- 参数返回实际吸附的可见参考层ID、轴/坐标、移动后锚点和残差。显示预览仅从这一结果画辅助线；取消/完成/改文档/工具/控制权时清除，不进入文档/导出。
- 与既有单槽显示预览整合，显示候选和最终应用必须是同一个已验证参数结果；不得绘制一套近似Swift吸附而实际提交另一组坐标。

## 检查

独立距离/并列/半整数/负及大坐标参考；可见与隐藏祖先、嵌套组、自身子树排除、空文字、锁、范围/源访问/共享内存/取消原子性。原生候选缓存复用、辅助线与真实改码位置一致、Esc/文档切换/AI接管不留旧辅助线。AI发现/描述/严格schema/实际组或文字吸附/回合撤销；必要真实Metal、Release与一个窗口完成即关闭。

均匀间距建议、旋转角度/尺寸智能提示及其他智能参考线子动作继续分别跟踪，不以边缘/中心吸附替代全部专业功能完成结论。
