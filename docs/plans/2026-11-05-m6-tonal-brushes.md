# M6 减淡、加深与海绵

- 三种实际手工工具共用圆形笔尖的 u16 覆盖、选区、压力、流量和整笔不透明度；首个输入锚定目标和 revision，独立取消，一笔一条历史。
- 减淡/加深提供阴影、中间调、高光范围，使用物理线性 P3 Y 对应的 CIE L* 权重。曝光量 0–1；保护色调时使用有界的亮度曝光曲线、保留黑白端点并向中性色压缩超色域色度；关闭保护时使用线性增益并显式裁切。
- 海绵提供增加/降低饱和度、强度 0–1、自然饱和度加权选项。以物理 Y 为中轴缩放色度，压缩超色域，保持亮度和 alpha；不拿普通色相/饱和度填充冒充局部工具。
- 新增通用有限区域逐像素变换发布器；覆盖只乘一次，预乘 alpha 插值，零覆盖/未变/完全透明受保护样本逐码保持，现有层/祖先锁和共享预算生效。所有路径在候选快照计算，失败不发布部分图块。
- 固定参考：中性灰色与有色夹具分别验证亮度单调、阴影/中间调/高光权重、保护端点、海绵去色后的线性 Y 误差 <=0.0001、原 alpha 逐码不变；软选区/压力/强度只乘一次。8/16 位、ICC、跨块/偏移、撤销/工程、取消和低预算均需实际断言。
- 原生 O 工具提供减淡/加深/海绵及上述设置，复用取消笔触反馈；真实压感和大图连续性能独立保留。无窗口回归先行，系统 UI 延迟恢复后只开一个实例做手工验收。
