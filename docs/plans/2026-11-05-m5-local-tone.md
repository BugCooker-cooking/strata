# M5 空间自适应阴影 / 高光

依赖当前的可取消合成准备接口；不能用一条全局曲线替代局部估计。

## 设计

- 使用独立 `shadows_highlights` 调整类型，阴影/高光强度 0–100、各自色调范围、半径 0–256；中性强度精确恒等。估计在线性 P3 的物理亮度 Y 上完成，不改变 alpha 或源样本。
- 半径定义为局部估计的有限支持范围；采用方差匹配的三次可分离盒滤波近似高斯，实际 halo 由三个核半径之和计算。卷积同时处理 `Y×alpha` 和 alpha，再除以有效 alpha，避免透明边缘的黑色污染。
- 画板边缘取最近有效像素；跨块邻域在画布坐标采集，只暂存一个前缀输入图块和有界亮度区域。所有临时缓冲纳入共享预算，逐块/逐行检查取消。
- 输入必须是该调整实际看到的前缀：穿透组继承父背景，隔离/非正常混合/剪贴/带样式的组从独立表面开始；剪贴调整只读取本链底层及其较早链成员。单独实现前缀输入函数，避免将父组不透明度、蒙版或外部背景提前作用于局部估计。
- 输出以局部低频亮度的阴影/高光权重调整线性 RGB 增益，再按调整层蒙版、不透明度和混合模式合成；不把局部估计当成源像素替换。
- 缓存依赖保守覆盖该调整之前所有相关源块/蒙版版本及祖先元数据，避免邻块改动后使用陈旧结果；不得把后面的曝光滑块参数加入前缀依赖而破坏已有复用。
- 原生参数面板、中文目录、严格 schema、独立例子、工程/恢复/撤销一起接入；实际性能与质量分开记录。

## 参考与验收

- 证明相同中心像素因邻域不同而有不同修正；零半径有确定的点参考，中性强度精确恒等。
- 将同一内容和画板整体平移到不同/负块坐标，输出保持一致，验证 halo 与块边界无接缝。
- 穿透组/解组一致、组不透明度、隔离组与剪贴半透明底层分别与独立前景合成参考比较。
- 透明边缘、蒙版外保护、相邻 16 位码、双位深工程/恢复、预算/取消失败原子性。
- 真实 Metal 对照和固定 Release 大图趋势；没有性能证据时不关闭实时预览/帧率门槛。
