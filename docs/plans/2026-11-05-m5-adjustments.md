# M5 调整图层与调色

接续 M3 图层和 M4 高精度选区接口，完整终止范围继续以 [PS 功能覆盖](photoshop-feature-coverage.md) 为准。已有曝光与色相/饱和度保持兼容。

## 实施顺序

1. 通用调整类型、严格参数校验与版本化工程结构；亮度/对比度、RGB/分通道色阶、RGB/分通道曲线先建立完整命令、原生面板、撤销/保存和像素参考闭环。
2. 自然饱和度、白平衡/色调、色彩平衡、黑白、照片滤镜、通道混合器；明确每种计算空间与参数单位，保留 16 位精度和 alpha。
3. 反相、色调分离、阈值、渐变映射、可选颜色、去色；各自单独的参数、隔离示例和手工入口。
4. 阴影/高光的局部亮度估计与跨块 halo、取消/预算、固定像素参考；不将简单全局曲线冒充空间自适应算法。
5. 直方图、目标通道与蒙版交互、实时预览；固定大图性能和 CPU/Metal 一致性。真实模型仍用已授权示例及独立网络验收，困难质量集与外部设备不计作已完成。

## 持续门槛

- 每个能力同时具备真实像素实现、命令/严格 schema、参数说明、手工 UI、单条历史、持久化/恢复与失败原子性。
- 调整保持源像素不变，alpha 与未选区域不被意外修改。默认参数为精确恒等，端点/中性灰/透明与相邻 16 位码有参考。
- 工作 ICC、线性合成与非线性调色空间分别定义；避免多层之间量化到 8 位。
- 所有本机验收串行，一次一个 Strata 实例，验收后立即退出。构建最多两个并发任务。
- 开发提交只推送已授权的私有 `codex/v1-remaining` 草稿 PR；不合并默认分支或发布。

首批三类调整、第二批点调色/白平衡、空间阴影/高光和可取消画布预览事务已具备核心、原生、Metal 与 Release 证据，见 [实现、数值与原生证据](../research/2026-11-m5-adjustments-progress.md)。继续处理 GPU 预览加速、固定原生性能和步骤 5；整体 M5 验收尚未关闭。[M6 绘画/修复](2026-11-05-m6-paint-retouch.md) 复用当前事务接口继续推进。
