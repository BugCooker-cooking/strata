# M6 高斯模糊、USM、杂色与滤镜预览

接续已实现的有限覆盖发布器。当前三种实际滤镜、单窗口参数/预览、核心与专项回归已到本机检查点，详见 [实际进展](../research/2026-11-m6-filters-progress.md)。完整回归、手工/质量/连续性能门槛分别保留，不能由命令名或说明推定完成。

## 像素路径

- `filter.gaussian_blur`：显式像素层，sigma 0.1–64px，核半径 ceil(3 sigma)，归一化真高斯权重，分离横/纵卷积。在线性 P3、预乘 alpha 中处理；画板外 clamp，画板内层外为透明。读取不可变原始像素，不把刚写入的结果作为下一块输入。
- 选区仅限制写入；halo 从原始层取样，不能截在选区边上。保留现有蒙版和层位置；透明锁保留原 alpha，普通模糊允许扩展/混合 alpha，零覆盖逐码保持。
- `filter.unsharp_mask`：复用上述 alpha 归一化模糊得到低频，amount 0–5、sigma 0.1–64、阈值明确为线性 RGB 差值；按阈值保留或增强高频，保留原 alpha、排除隐藏 RGB。参数必须公开实际颜色空间和裁切语义，不宣称 Adobe 像素一致性。
- `filter.add_noise`：实际工作编码 RGB 上的确定性均匀/高斯杂色，归一化 amount、u32 seed、单色开关；坐标/通道散列独立于图块顺序。保留 alpha/隐藏 RGB、工作 ICC 和 8/16 位，禁止通过 8 位中间图处理 16 位源。
- 使用固定大小的逐块 halo 缓冲；最大 Gaussian patch 640×640，源图块逐个转换后拼接到 patch，避免逐像素反复 ICC 转换或因 8 块缓存不足而抖动。核/halo/横向中间值/输出缓存/候选图块均明确预留共享预算；最多缓存一个已算好的输出图块，换块前先释放旧缓存。
- 逐行/块检查独立取消 token；非法参数、锁、低预算、取消或显示准备失败均不发布部分文档。一条滤镜命令只生成一条历史。

## 预览和手工入口

- 原生参数放在当前窗口内，滑动连续变化使用 120ms 合并和单次后台计算；原始文档/revision/控制 epoch 固定，不对前一个预览累加。
- 预览仅提交显示候选，工程/保存/历史仍读取原文档；应用时只发布最后有效候选并加一条历史，取消恢复原场景。序号过期、文档切换、AI 接管、新命令、超时和内存失败拒绝迟到候选。
- 复用已有可取消显示准备/Scene 保留规则；不得把 CLI CPU 命令时间当成原生连续帧率或完整实时滤镜证明。

## 冻结数值参考与门槛

- Gaussian：常量不变、单位脉冲核归一化/对称、独立直接二维小图卷积参考（浮点 alpha/RGB 误差 <=0.0001，整数输出按位深容差）、画板边界/负坐标/移动层、跨块平移不变；透明洋红隐藏色不得污染可见边缘。
- USM：独立固定阶跃参考、amount=0 精确恒等、阈值保护、锐化/裁切可见差异、alpha 逐码保留。
- Noise：同 seed/坐标逐码一致，换 seed 产生不同数据；单色相同通道扰动、两种分布的固定样本/统计参考，8/16 位量化明确。
- 所有路径验证 u16 软选区只乘一次、外部像素精确保护、像素/祖先锁、撤销/恢复/真实工程、低预算、准备中取消和原生应用/取消。命令目录、严格参数/中文搜索、全部隔离示例、真实 Metal 显示对照和 Release 均需通过。
- 固定 24MP CPU/峰值内存报告与原生连续预览性能分别记录；手工验收只有一个实例，完成即退出。实际照片质量和硬件门槛继续保留。
