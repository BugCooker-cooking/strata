# M2b 最小局部修图闭环

2026-11-04。接续 [剩余开发计划](2026-11-04-v1-remaining.md)，M2a 本机回放/原生回归已通过，真实服务密钥配置等待用户完成。先推进不依赖该凭据的选区、蒙版与曝光基础，不据此关闭 M2a 真实模型门槛。

## 共享接口与顺序

1. **遮罩真值**：256×256 单通道 u16 分块、稀疏默认覆盖值、COW、全局源预算/LRU/校验磁盘后备；带明确边界，边界外为零。矩形、反相、全选/取消和组合为同一遮罩接口的使用者。
2. **工程**：容器增加明确的通道数和新版本，保留旧 v0 的读取；图层蒙版与文档选区用独立命名的平面。未知版本/孤立块/通道错误/尺寸超限拒绝，不静默降位深。恢复共用同一来源接口。
3. **图层与合成**：新增可扩展的图层类型、曝光参数和蒙版元数据；曝光在线性光中做乘法并按蒙版和图层不透明度插值，原像素不变。缓存指纹纳入调整参数和蒙版版本，原有无蒙版照片路径保留。
4. **命令与界面**：选区与蒙版、曝光均注册命令；矩形拖动和参数预览用交互会话；暂停时用户可指定矩形，恢复附最新状态；手工入口、直方图和基础蚂蚁线同步交付。
5. **主体模型**：单一宽松许可 ONNX 模型，固定下载地址、许可证、版本和 SHA-256；先做 CPU 真实推理与取消，再验证 Core ML 可用性。下载须原生确认、显示进度并校验，失败不提交选区。
6. **评测**：在跑真实模型前固定十张许可照片、目标/保护区和阈值；两种协议下的工具/视觉模型各三次，分别计算成功率与介入率。不以回放替代真实质量验证。
