# M6 仿制与修复

复用圆形笔尖覆盖、输入压力、选区、像素锁和单条历史；仿制与修复不能混称同一算法。

## 仿制图章

- 命令显式给出目标像素层、采样源（当前原始像素层/可见合成）、源/目标锚点、对齐方式和笔触。原生 ⌥ 点击设源，显示源标记；每笔从不可变输入读取，禁止自我复制时把刚绘制像素再次取样造成拖影。
- 输入采样在画布坐标，链接图层偏移和画板边界明确；双线性采样预乘线性颜色/alpha，透明源不把隐藏颜色带入结果。
- 使用圆形覆盖后对源色进行正常 over 混合，遵守整笔不透明度、流量、压力、透明锁和当前选区；一笔一条历史、工程恢复和可取消预算。
- 对齐开启时保持跨笔的源/目标偏移；关闭时每笔从同一源锚点开始。两种模式都有人机参数入口。

## 修复画笔与污点修复

- 修复保留源纹理并匹配目标低频/边界；建立固定图像和边界误差参考，不能把普通复制笔尖标成修复。
- 污点修复至少有明确近似匹配/纹理创建算法，内容识别 PatchMatch 独立实现/验收。
- 先冻结可审查的生成纹理/边界夹具与阈值，再运行参考和真实示例；照片质量与单次可见效果分开记录。

所有路径保持核心 Linux 可移植；原生验收一次一个实例，完成即退出；完整 PS 其余能力继续追踪。

## 自动污点修复的下一检查点

- `retouch.spot_heal` 在笔触以外查找近邻纹理；使用有界、确定性的平移候选搜索，以笔触边界颜色/纹理误差选择源，再进行同一梯度域融合。公开搜索范围、误差和所选源点；这属于近似匹配模式，完整内容识别 PatchMatch 另行交付。
- 源区域与目标笔触的包围盒及边界不相交，保持在画板内；透明边界拒绝作为候选，无有效源则原子失败。原始层/可见合成取样明确，未给定源点也能手工完成污点修复。
- 搜索范围最多 512px、采样边界最多 128 点、候选最多 2048 个；逐候选检查取消，纹理采样与融合沿用共享内存预算和单笔历史。
- 先固定参考：16 位平坦底色上的孤立色斑消除后中心误差不大于 8 个码值；周期为 8px 的灰阶纹理上覆盖孤立色斑，融合后中心相对无斑参考的线性 RGB 误差不大于 0.003；笔触外逐码不变。两者均验证确定性、单次撤销和工程往返。
- 原生修复工具提供“取样修复 / 污点修复”入口；污点模式不要求 ⌥ 取样。实际照片单窗口操作只证明工具链可用，不能替代照片质量集或宣称完整内容识别能力。
