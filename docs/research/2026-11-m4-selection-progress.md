# M4 选区系统进展

2026-11-05，接续 [M4 计划](../plans/2026-11-05-m4-selection.md)。本页记录已经交付的选区能力与独立验收门槛；[完整 PS 清单](../plans/photoshop-feature-coverage.md) 的后续 P1–P3 范围继续有效。

## 已实现

- 矩形、椭圆、自由套索、多边形；椭圆和偶奇规则多边形使用 4×4 子采样、u16 覆盖。四类选区运算和重新选择共用同一核心实现。
- 高斯羽化（sigma ≤8 精确可分离核；更大半径为方差匹配的三次盒滤波）、欧氏扩展/收缩/边界、软阈值平滑。越界视为零覆盖；所有操作限于画板。
- 独立选区仿射变换：逆映射、像素中心与双线性覆盖；图片和图层蒙版均不被修改。
- 魔棒：工作空间 RGBA 最大通道差容差，0–255 按 16 位比例比较；四连通或全图匹配；可见合成/当前像素层取样。完全透明样本忽略隐藏 RGB。
- 快速选择：最长边 ≤256 的像素中心预览，前景/背景笔触约束、对角高斯颜色代价及网格最小割；迭代 Dinic 避免深递归。无背景笔触时用未标记的预览边缘作为背景；粗网格冲突明确拒绝。双线性上采样为 u16 覆盖。这是传统颜色分割，未作为语义模型质量证据。
- 算法和选区组合均检查取消；临时样本、图结构、稠密覆盖纳入共享预算。先准备候选，再校验文档 revision/control epoch 并提交，拒绝迟到结果。
- 上一个选区单独持久化为 mono plane，manifest v3，容器保持 v1；旧工程按缺省兼容，新元数据伪装成旧 manifest 时拒绝。撤销、真实文件重开和崩溃恢复都保留重新选择能力。
- 原生工具栏有形状/套索模式、魔棒参数、快速选择前景/背景笔触、选区运算、重新选择及修改/变换弹层。多边形双击或回车闭合；快速选择回车计算；Esc 取消暂存输入。耗时准备离开主线程和引擎状态锁。
- 模型管理显示固定版本、许可、SHA-256 与来源；CPU/Core ML 切换；支持受校验版本的离线导入/替换、取消下载和缓存移除。导入复制有大小上限，校验后原子发布；失败保留原缓存。

## 本机证据

- 9 项选区集成测试，覆盖双位深取样、透明 RGB、连续/全局与四类组合、跨块、软边几何、羽化/仿射、真实工程与恢复、暂停后的用户修正、准备中预算/零磁盘失败原子性。
- 核心单元测试另核对负坐标与相邻 16 位码、粗预览软边及种子冲突；最小割能量与穷举参考一致。FFI 手势回归检查过期、取消、错误命令及单条历史。
- 86 个命令的隔离示例通过；命令参考由注册表生成。Clippy、格式、SwiftLint 和可移植性持续作为提交门槛。
- 最终全仓 Rust 回归 241 项通过；Release 原生构建、格式/Clippy/SwiftLint/可移植性/覆盖文档检查和 86 命令示例通过。
- 原生 XCTest 35 项：34 通过，1 项真实网络测试显式跳过。包含多边形/椭圆/魔棒/多笔触快速选择交互，以及无效/超限/符号链接模型导入保留原缓存。
- 单窗口 CUA 验收实际提交椭圆、羽化、选区平移和前景/背景笔触图割；核对模型版本/许可/哈希。8 条测试历史全部撤销，示例恢复无未保存修改，退出后确认 0 个 Strata 实例。
- 固定 24MP / 16 位命令基准由 `strata-devtool selection-benchmark NEW_REPORT` 生成；报告中的单次命令耗时、预算峰值与颜色断言分别记录，不当作显示帧率或照片质量成功率。
