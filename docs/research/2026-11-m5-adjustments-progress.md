# M5 调色进展

2026-11-05，按 [M5 计划](../plans/2026-11-05-m5-adjustments.md) 接续。M4 `fd00f17` 的 Linux/macOS CI 已通过；当前阶段继续补齐调色，完整 PS 范围仍包含后续 P1–P3。

## 首批已实现

- 通用、严格类型的调色调整层：`layer.add_tonal_adjustment` 和 `adjust.tonal.set`；当前支持亮度/对比度、色阶和曲线。默认使用当前选区蒙版，没有选区时使用白蒙版。替换设置要求保持类型，避免无意转换图层。
- 亮度先在编码工作 RGB 中加 `brightness / 100`；对比度围绕 0.5 缩放，负值增益 `1+c`、正值 `1/(1-c)`，+100 为硬阈值。范围 ±100。这是明确的传统调色公式，没有宣称与 Photoshop 的专有现代算法逐像素一致。
- 色阶先主 RGB 再独立 R/G/B：归一化输入黑白点、Gamma 0.1–10、输出黑白点；支持反向输出。禁止重合或反向输入端点。
- 曲线先主 RGB 再分通道，2–64 个点，x 严格递增、端点 x=0/1。保持形状的 PCHIP 三次插值支持非单调 y，在每段端点范围内不产生过冲。编辑图预览与实际渲染调用同一核心插值。
- 使用浮点工作 ICC 转换处理有界合成块；调整之间不量化到 8 位。默认中性设置在普通混合模式精确跳过，保持源样本，包括相邻 16 位码。alpha 不参与调色；选区蒙版、填充/总不透明度、混合和祖先锁继续生效。
- 参数参与合成指纹、撤销、恢复、复制、分组和项目保存；manifest v4 表达新结构，容器仍为 v1。伪装旧 manifest 的调色类型被拒绝。
- 已接入栅格化、蒙版应用和剪贴板边界：调整不能被孤立拷贝；栅格化需明确合并下方输入；样式和剪贴链底图拒绝调整内容。
- 原生三类调整入口、RGB/分通道面板、数值编辑、曲线拖点/添加/移除/键盘数值；参数草稿“应用调整”一次提交一条历史，明确提示尚未应用状态。

## 第二批：点调色与白平衡

同一严格类型接口再加入 12 类调整；原生有独立参数、颜色选择与通道/颜色范围入口，参数草稿应用一次形成一条历史。

| 类型 | 计算与参数 |
|---|---|
| 自然饱和度 | 自然/整体饱和度 ±100；优先低饱和区域，橙色肤色范围降低增强强度；保持编码 RGB 加权亮度 |
| 色温/色调 | ±100；6504K/D65 基准下的倒数色温偏移，正值偏暖；Bradford 在线性 P3 中适配；正色调偏洋红，可保持物理 Y |
| 色彩平衡 | 阴影/中间调/高光各三轴 ±100；按编码加权亮度分配范围；可保持亮度并限制色域 |
| 黑白 | 红/黄/绿/青/蓝/洋红六类色相响应 −200…300；可着色与控制着色强度 |
| 照片滤镜 | 当前工作空间的 RGB 滤色、浓度 0…100；可保持编码加权亮度 |
| 通道混合器 | 每个输出通道三系数与常数，−2…2；单色模式有独立混合行 |
| 反相 | 编码工作 RGB 各通道 `1-v` |
| 色调分离 | 每通道 2…65536 级；输出保留文档位深 |
| 阈值 | 编码 RGB 的 Rec.709 系数加权阈值 0…1，等于阈值时为白 |
| 渐变映射 | 2…64 个严格递增色标，0/1 两端固定；工作 RGB 亮度映射、编码 RGB 插值和反向 |
| 可选颜色 | 红/黄/绿/青/蓝/洋红/白/中性/黑九范围 CMYK 偏移 ±100；相对按通道/余量缩放，绝对直接偏移 |
| 去色 | HSL 明度 `(min+max)/2`，与六色黑白混合不同 |

以上是可复现的传统等效算法，没有将 Photoshop 专有实现的像素完全一致作为已完成结论。源样本、蒙版、alpha、锁、分组、持久化与历史沿用通用调整层。

## 耗时准备的取消与界面响应

阴影/高光的空间处理开始前，先补齐通用准备路径：

- 取消句柄独立于编辑器/渲染锁，撤销已有 token 后发布新代；后续请求不会复活已取消的候选。
- AI 停止先标记对应回合的 token，再等待状态锁；旧回合停止不会取消新回合。准备被取消时返回停止状态，保留已经提交的步骤。
- 显示准备逐块检查取消，检查继续传入嵌套组、剪贴链和样式区域；完整 CPU 导出合成也可以中途停止。取消的部分图块不进入缓存、文档或显示交换。
- 显示回调、画板/缩放读数和导航输入在编辑锁忙碌时不会阻塞 UI；本机后台工作期间避免开启新的工具手势。基准模式保留自己的连续绘制路径。
- 显式取消不再弹出错误对话框；完成的形状选区仍清除暂存轮廓。

## 阴影 / 高光首轮实现

## 显示预览事务进展

- 原生“画布预览”支持三类色调、十二类点调色/白平衡与空间阴影/高光。合并 120ms 内输入，单个后台任务准备最新参数；新序号立即撤销旧工作的显示交换资格。
- 预览只交换渲染场景，文档、dirty、历史、工程和恢复仍使用已提交内容；应用时再调用同一严格核心命令，形成一条历史。
