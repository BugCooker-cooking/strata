# P0 功能核对

2026-11-16，依据 [P0 验收矩阵](../plans/2026-11-02-p0-acceptance-matrix.md) 核对现有 P0 功能。单项状态和关联命令见[功能清单](../plans/photoshop-feature-coverage.md)及 [AI 入口审计](../plans/ai-editing-entrypoint-coverage.md)。

- 整图缩放、任意角度旋转、拉直及自由变换覆盖已有图层类型。填充在原渐变坐标中计算颜色，保存有限边界及有序的删除裁剪。调整图层保留参数，联动蒙版随几何变换。在图层右键菜单可加入或移出选择，再按 ⌘T 一起变换。父组和子层同选时子层只变换一次。画布手柄、数值面板及 AI 使用同一命令，单次应用可一次撤销。
- Strata 继续读取旧工程。工程含新填充几何时写为 manifest 10，需要支持该版本的 Strata 打开。点文字和段落文字保留原文、字号与段落参数，重新编辑时沿用已应用的变换及删除裁剪。内置字体缺字时，原生界面给出指引。
- 污点修复的近邻匹配、创建纹理及内容识别使用同一笔触覆盖和求解器。三种模式分别使用附近完整纹理、由边缘合成的细节及按方向延续的颜色结构。可指定当前层或可见合成取样。
- Strata 菜单可选简体中文或英语，选择后重新打开应用生效。菜单、检查器、工具参数、确认提示和错误信息使用同一套界面语言。界面语言由原生应用管理。
- 属性面板显示 RGB 模式、位深、工作 ICC 和分辨率。图层、文字、调整、样式及蒙版可手工编辑，并走现有命令。脚本入口用 `strata-devtool run` 执行 JSON 命令序列。[可运行的缩放另存示例](../commands/resize-and-save.json)

图层基础能力的各动作沿用 [M3 基准](2026-11-m3-layers-progress.md)及后续 M6、M7 回归。移动、参考线与吸附以 [智能参考线](2026-11-m7-smart-guides-progress.md)和[标尺原点](2026-11-m7-ruler-origin-drag-progress.md)的本机与单窗口记录为准。文字的既有 [CJK 编辑](2026-11-m7-editable-text-progress.md)和[栅格化撤销](2026-11-m7-text-rasterization-entrypoints.md)有独立验证。

完整 Rust 工作区在强制真实 Metal 下通过 631 项。按配置跳过的 ONNX 用例随后使用本机验证过的模型和运行库通过，实测主体选区、蒙版曝光、撤销和工程重开。Rust 与 Metal 覆盖三种污点修复、变换保留可编辑源、无效输入原子拒绝及撤销。最终完整 XCTest 129 项通过，联网模型用例跳过。Clippy、Rust 格式、SwiftLint、可移植性与双语文案占位检查通过。148 条注册命令的 222 个隔离示例执行成功。脚本的 320 × 480 RGB 工程已实际保存并重开，文档和图层标识匹配。

单窗口 Release 验收使用独立应用偏好的验收副本。原生添加渐变填充，从照片的图层菜单把照片加入选择，⌘T 显示两层并提交一次位移。照片和可编辑渐变的 X 都为 10、Y 都为 0，历史仅新增一条“多图层自由变换”。撤销后两层恢复原位，再撤销创建恢复原始单层照片。语言菜单选 English 后正常退出、重启，菜单、检查器、AI 助手和污点修复三种选项可读。后续校正了缩放工具及部分 VoiceOver 名称。验收结束时应用已退出，样例原件指纹一致。

最终 arm64 Release 在本机 macOS 27.0.1、Xcode 27.2 构建通过，应用资源中的英文文案与样例均和仓库一致。Release 可执行文件 SHA-256 为 `60c66554e424dc486bb0c9152e57a268423c2645df6add109c7f55d4c8181efb`。
