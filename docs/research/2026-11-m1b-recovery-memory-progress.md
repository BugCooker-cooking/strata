# M1b 第三批：导出尺寸、HEIC、恢复与内存后备

2026-11-03/04。文件功能、无界面压力与自动化回归已通过；原生创建和崩溃后恢复已实测。完整交付门槛仍保留设备、解锁屏幕、提交和远程 CI 条件。此记录覆盖本机实现与验证，不代表完整检查点、标准机或最低系统验收。

## 已实现

### 导出尺寸

- `file.export` 可选 `width` / `height`，必须同时为正整数；省略或等于原尺寸时保持原样本路径。按文档位深计算的输出数据仍限 512 MiB，另受全局预算约束。
- 缩小用面积滤波，放大用像素中心双线性滤波，在线性 Display P3 中按预乘 alpha 处理。浮点中间数据按行处理，不制造整张浮点副本；最后转换输出 ICC 并保持原位深或执行已确认的量化。
- 原生导出面板提供像素宽高及默认开启的原图比例锁。原文档尺寸、样本、历史与脏状态保持不变。此功能是输出副本缩放，不是 M7 的可撤销“图像大小”。

### HEIC

- 新增 `strata-platform`，macOS 的 ImageIO/CG/CF 调用集中在此；portable crates 使用受信 `PlatformDecoder` 接口。原生外壳和开发工具绑定同一适配器，打开/置入都经过资源授权、预检及提交前复核。
- 按文件签名识别 HEIF，读取主图，保留可导出的 RGB ICC 和系统解码所得 8/16 位整数深度，规范化 EXIF 1–8 方向；返回 straight RGBA。
- 本机生成的 8 位 P3 HEIC 验证了颜色方向、旋转后尺寸、伪装扩展名、打开/置入/撤销、损坏与超限拒绝。16 位方向变换保留相邻码值。
- 本机 ImageIO 生成并解码了 10 位 RGB101010 HEIC；适配器将整数 10 位按全量程提升为 Rgba16，保留 RGB/alpha 与 ICC。浮点/HDR 增益图、深度图、序列辅助内容仍明确拒绝或不纳入 M1 文档真值。其他平台仍明确拒绝 HEIC，不将 macOS API 带入核心。

### 自动恢复

- 文档脏状态在 30 秒空闲后触发检查点，计时器按 1 秒轮询；文档忙碌时顺延，写入失败后再隔 30 秒尝试。期间继续编辑不会将旧检查点误认作最新内容。
- 恢复目录是 Application Support/Strata/Recovery，目录权限为 0700，文件使用会话 UUID 命名。首份副本/文档替换为临时工程验证后原子发布；同一文档后续检查点通过 FULL synchronous SQLite 事务更新变化块。
- 状态栏显示最近成功时间、等待/写入或失败状态。检查点不清脏、不改变项目路径、历史或普通文件执行记录。提交前失败保留上次完整检查点；已提交后同步失败按持久性未确认处理，不声称旧文件未变。
- 启动提示及“文件 → 恢复未保存文档…”提供恢复/稍后/丢弃。损坏副本保留供重试；正常保存、关闭或退出按用户决策清理。热 rollback journal 在私有副本中读取，丢弃时一并清理该会话 journal。
- 注册 `file.recover`，只接受授权读取资源；全部校验、显示准备和资源复核成功后恢复为未保存文档。`original_path` 只是记录，不授权读写原件；恢复后须另存。退出等待后台清理完成，长磁盘 IO 不放入主线程。

### 全局像素与显示资源预算

| 范围 | 当前默认额度 |
|---|---|
| 进程内各文档共享的源块、CPU 合成缓存、暂存预留 | 合计 2 GiB |
| GPU 纹理、缓冲、画布目标估算 | 512 MiB |
| 匿名临时块后备文件 | 32 GiB |
| 单文档源块逻辑总量 / 图层 | 16 GiB / 128 层 |
| 历史条数 / 当前与历史候选引用的独立块逻辑量 | 64 条 / 24 GiB |
| 画板、解码、平面导出 | 各 512 MiB，另受共享额度限制 |

- 所有默认引擎共用一个池。先全局淘汰可重建 CPU/GPU 缓存，再按最近访问顺序将源/历史块写入同一个匿名临时文件；空洞合并并复用。系统内存压力通知触发主动淘汰。
- 不可变源块与 COW 历史共用身份和后备，不以低位深缓存替代源数据。读取者固定块及对应额度；磁盘回载验证 SHA-256，磁盘错误、损坏或额度不足会返回错误，不生成假的零像素。
- 淘汰索引只保留驻留对象；回载重新登记，代次检查防止并发回载被旧淘汰操作误删。CPU 合成缓存、GPU 纹理与暂存预留跟随资源生命周期释放。
- 工程命令逐块读取/写入 SQLite；不先把全工程复制成内存 archive。容器仍为 v0、固定小端 16 位块；旧工程可读。内存 archive 辅助接口保持 512 MiB 限制。
- 这些是托管像素/显示资源额度，编解码器 scratch 采用估算。元数据、原生图像副本、驱动和系统开销另计；GPU drawable 按三份 RGBA8 估算。不能将额度或统计器称为整个进程 RSS 的硬上限。

## 验证

- `STRATA_REQUIRE_GPU=1 make test-app`：22 项 XCTest、完整 Rust workspace 和真实 ImageIO/Metal 回归通过。SwiftLint 0.59.1 也已加入 macOS lint gate；沙箱内不可调用 HEIC 编码器时未用跳过替代验证。
- 新测试覆盖透明边缘不渗色、线性光缩小、8/16 位尺寸/ICC/状态不变、非法尺寸不覆盖目标；HEIC 方向/ICC/损坏/额度；恢复无原件写权限、显示准备失败保留文档；强制子进程在增量检查点提交前退出后，仍发现并恢复上一份完整副本。
- 真实原生计时器测试等待 32 秒，确认产生恢复副本、文档仍脏；保存成功后副本清理。另有纯调度测试覆盖忙碌顺延、写入期间编辑与失败重试。
- 多文档共享额度、固定读取者、源/历史淘汰与回载、并发加载、后备校验、写入失败及额度释放通过。热 journal 丢弃清理另经 4 项针对性恢复回归验证；随后比例锁与调度边界的 5 项原生定向复核通过。
- `make lint`（fmt、clippy、SwiftLint、可移植性检查）、28 个命令隔离示例、自动生成命令参考、原生 Release 构建通过。当前 Mac 已实测强制退出 → 启动提示 → 恢复副本：A4、300 dpi、16 位、Display P3、白色背景和命名图层逐项恢复，并保持未保存状态；副本另存为工程前保留。实现提交 `8835925` 的精确源码独立 clean-build 已通过（[证据](data/2026-11-04-m1b-clean-build.json)）；远程 CI 继续跟踪。

### 50MP × 30 独立 16 位工作集

命令：

```sh
cargo build --release --locked -p strata-devtool
/usr/bin/time -l target/release/strata-devtool memory-stress build/new-memory-stress
```
