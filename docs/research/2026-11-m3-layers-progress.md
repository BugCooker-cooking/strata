# M3 图层系统进展

2026-11-05，接续 [实施计划](../plans/2026-11-05-m3-layers.md)。发起人已将目标扩展到 [完整 PS 清单](../plans/2026-11-05-photoshop-full-scope.md)，本页只记录当前图层子系统的实际实现。

## 已实现的图层能力

- 27 种混合模式：W3C 分离/非分离公式与摄影模式扩展，在线性 Display P3 合成；Dissolve 使用固定哈希与图层 UUID/画布坐标，不随进程、缓存或重开闪烁。
- 填充不透明度、颜色标签、透明/像素/位置/全部锁；命令入口检查祖先组锁，长变换和像素操作保留失败原子性。
- 嵌套组、编组/解组、重设父组、子树移动/复制/删除；默认穿透合成保持组内调整对父背景的作用，隔离模式另有开关。拒绝环、孤儿和超过 16 层的树；已有工程 v0/v1 按缺省兼容，manifest v2 表达新结构。
- 剪贴链、纯色/线性或径向渐变填充、色相/饱和度调整；填充保留创建时的几何尺寸，颜色与样式随工作 ICC 转换。
- 蒙版应用、像素/生成图层/组栅格化，调整栅格化需显式合并下方输入；四类合并保留各自的源层语义。提交前比较合成结果，超过 8 位 1 码/16 位 3 码时保留原结构并返回指引。
- 多图层对齐与中心/间距分布，以实际占用像素或生成几何边界为依据，组移动整个子树；锁定或祖先重叠目标拒绝。
- 五种样式：投影、描边、外发光、颜色叠加、渐变叠加；高精度 alpha、跨块 halo、独立填充/总不透明度，样式可撤销并随工程恢复。
- 剪切、拷贝、合并拷贝、粘贴、原位粘贴、清除；选区衍生图层。剪贴板图像用受限能力绑定来源/回合，剪切只有系统写入成功的宿主回执后才清源 alpha。系统剪贴板写入不承诺文档撤销恢复；8/16 位 TIFF 转移精确保持样本与 ICC。
- 原生层树/折叠、多选、混合/锁/标签、填充/HSL/样式、排列和栅格化/合并入口。手动菜单区分文本编辑与像素操作；测试使用命名剪贴板，不读取或覆盖用户系统剪贴板。

## 验证

- 一轮完整正常本机权限回归：227 Rust、31 XCTest 中 30 通过与 1 个显式 opt-in 网络测试跳过；后续小增量按实际日志另记，不把跳过当成真实模型通过。
- 74 个命令的隔离示例；格式、Clippy、SwiftLint、可移植性通过。完整 PS 覆盖文档由 265 个综合条目生成并加入 lint 检查；一个综合条目不等于一个单独功能。
- 27 模式固定参考、透明极值、双位深导出/工程、稳定溶解；父组锁与树故障；穿透/隔离与调整编组；剪贴链；线性光/预乘渐变；蒙版应用/栅格化/合并原子性；五类样式的参考形状与双位深对照；剪贴板跨来源/未确认/过期与暂停回放。
- 真实 Metal 的现有渲染回归通过，分组/渐变/蒙版/描边投影的输出与 CPU 参考比较通过；比较使用精确映射的像素中心，保留插值边界测试，不放宽像素误差阈值。
- 单窗口原生冒烟完成：默认穿透编组、折叠、五种样式入口及白色 2px 外部描边实际提交；恢复原示例、退出后 CUA 清点 0 个 Strata 实例。
- Release 构建通过。大图样式首次准备仍需性能优化与固定趋势报告；未把 Debug 操作耗时当成 Release 帧率证据。

## 尚待验收与后续

- M3 两模型四类任务的网络验收在钥匙串读取处被系统等待，已终止旧测试并实现后台限时读取；真实调用未开始的运行不算通过。
- M3 最新增量的远程 Linux/macOS CI、独立干净构建及固定多层性能；实现分支尚未更新默认分支。
- 蒙版画笔仍属 M6；其余调色类型属 M5；文字样式与栅格化在 M7 集成，未据当前图层框架提前宣称完成。
