# M0 实机验收记录模板

状态：当前 Mac 部分已验证，其余待复验。2026-11-02 发起人确认先使用当前 Mac，其他设备暂缺。此表用于补齐自动化无法证明的显示与输入行为；已有数值测试和 M4 基准见 [M0 进度](2026-11-m0-progress.md)。没有对应设备的项目写“未验证”，不要以部署目标编译成功、系统配置文件名称或截图代替实测。

## 准备

1. 记录 `git rev-parse HEAD`、机器型号/内存、系统版本、屏幕型号、系统缩放与刷新率。
2. `make run CONFIGURATION=Release` 打开应用。使用已有 `build/color-fixtures-v1`；若不存在，运行 `make color-fixtures`。重建时用新的 `FIXTURE_OUTPUT`，生成器不会覆盖原文件。
3. 对色时记录显示器模式和系统配置文件，确认同一 P3 屏幕。由测试者确认 True Tone、Night Shift 等自适应显示均关闭，测试结束后自行恢复原设置。

## 本轮实测与限制

- 当前机器 M4 Mac mini / 16 GiB / macOS 27.0.1，G27M7Pro，scale=2，系统配置文件为 Display P3；运行 `a4c873a` 源码对应的 Release 应用，错误提示随后用本轮改动重建复验。
- `p3-swatches.png` 正常打开并标示 `768 × 512 · Display P3 · 8 位`。仅确认显示接线，不把截图作为 P3 对色证据。
- 在透明边缘图已缩小时打开故意伪装为 PNG 的文本文件，弹出失败提示；关闭提示后图像、位深和原视图保留。发现错误弹窗显示内部 Swift 枚举，已改成中文原因并在新 Release 中复验。
- 数码测色计保持“显示原生值”、Display P3 模式和原光圈设置；自动化指针与测色计实际采样未能可靠对应，读数未纳入上表。2026-11-04 发起人已确认 Night Shift/True Tone（若支持）关闭、显示器模式稳定；当前自动化取样位置仍未可靠对应目标，未将读数填为通过。
- 2026-11-04 的 `c55cab6` 已以真实窗口回调和恢复帧补齐三轮最小化/恢复；旧的不充分尝试不算通过依据。程序驱动鼠标与菜单不代替物理触控板验收。
- macOS 14、M1 标准机及 Retina/非 Retina 跨屏按“设备暂缺”追踪，不重复要求提供设备，也不将其标为通过。
