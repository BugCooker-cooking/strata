# M0 实机验收记录模板

状态：待执行。此表用于补齐自动化无法证明的显示与输入行为；已有数值测试和 M4 基准见 [M0 进度](2026-11-m0-progress.md)。没有对应设备的项目写“未验证”，不要以部署目标编译成功、系统配置文件名称或截图代替实测。

## 准备

1. 记录 `git rev-parse HEAD`、机器型号/内存、系统版本、屏幕型号、系统缩放与刷新率。
2. `make run CONFIGURATION=Release` 打开应用。使用已有 `build/color-fixtures-v1`；若不存在，运行 `make color-fixtures`。重建时用新的 `FIXTURE_OUTPUT`，生成器不会覆盖原文件。
3. 对色时记录显示器模式和系统配置文件，确认同一 P3 屏幕。由测试者确认 True Tone、Night Shift 等自适应显示均关闭，测试结束后自行恢复原设置。

## P3 与预览交叉验证

- [ ] 用 Strata 和系统“预览”分别打开 `p3-swatches.png`，放在同一屏幕并使用相同缩放。
- [ ] 数码测色计选择相同输出色彩空间、相同读数格式及采样范围；记录模式名称。采集每个大色块中心，远离边缘，鼠标与采样浮窗不要遮挡目标。
- [ ] 下表所有 RGB 通道差值绝对值 ≤2（8 位读数）。比较的是两应用的相同显示读数，不要求屏幕读数等于文件中的源 RGB。
- [ ] 用 `p3-alpha-edge.png` 检查透明红与不透明白的边界，不应出现红色晕边。两应用若背景不同，先记录背景条件，不能直接比较混合后的数值。

## 输入与窗口生命周期

- [ ] 打开 24MP 图片，真实触控板连续平移/捏合 30 秒：缩放围绕手势位置、惯性平移自然，松手可继续操作；出现卡顿须记录，不能用程序轨迹替代输入延迟检查。
- [ ] 最小化后恢复 3 次，每次确认画面完整、平移缩放仍有效；不出现黑屏或错误弹窗。
- [ ] 调小/放大窗口，移动到 Retina 与非 Retina 屏幕，来回 3 次；记录两边 scale。图像的屏幕逻辑大小与锚点不应突跳，画面按新密度重绘。
- [ ] 关闭最后一个窗口应退出；重新启动仍能打开并显示示例图片。重复 3 次，确认没有崩溃。

## 标准机与最低系统

- [ ] 在 M1 MacBook Air 上运行 `make benchmark`，保留独立 `report.json`。三轮必须分别 ≥58fps、p95≤20ms，记录内存和最长停顿；与 M4 结果分开。
- [ ] 在 macOS 14 的 Apple Silicon 设备上运行构建产物，验证启动、打开 8/16 位图、打开失败保留原图、平移缩放和退出。记录系统 patch 版本；macOS 15 CI 不能代替此项。
