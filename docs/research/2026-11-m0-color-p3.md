# M0 色彩与位深验证（数值通过，屏幕对色待测）

## 目标与方法

Little CMS 2（lcms2 6.2.0，静态构建其 MIT 库）；测试 8/16 位 ICC→Display P3，不覆盖源文档。P3 profile 使用 D65、P3 原色、sRGB 分段传输函数。

## 结果

- sRGB 红色转换到 P3 约 `[234,51,35]`，8 位误差 ≤1；黑白及 alpha 保留。
- P3 自转换完整 65536 级灰阶逐样本一致；相邻 32768/32769 可区分，16 位 PNG/TIFF 解码精度不丢失。
- 512 组 RGB 采样的 16 位转换，相对 lcms 浮点路径量化后每通道误差 ≤2/65535；alpha 精确复制；不替代将来的独立算子黄金图。
- 损坏 ICC 按 sRGB 回退并标记；能解析但非 RGB 的 ICC 明确拒绝，不把 CMYK profile 套到 RGB 像素。
- 带 P3 ICC 的示例已生成；**尚未与“预览”在 P3 屏幕实测，不能标记显示色彩通过。**

## 遇到的问题与 M1 结论

ICC 序列化系数有限精度，即使同一配置也可能在 PCS 往返中损失相邻值。完全相同的配置不重复转换；不通过名称猜测 profile 相同。屏幕浮点缓存与源文档分离，16 位导出不能从屏幕回读。HEIC、灰度/CMYK ICC 与工作空间编辑在 M1；原生广色域色块和屏幕读数待补。
