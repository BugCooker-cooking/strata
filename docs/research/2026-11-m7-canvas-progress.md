# M7 画布大小与有限参考坐标检查点

2026-11-06，仅本机验证。本页实现画布边界修改；图像重采样、删除裁剪像素、拉直、显示全部和完整 M7 仍待后续。

## 行为与工程兼容

- `image.canvas_size` 只修改画板边界，支持严格的宽高与九种固定锚点；中心遇奇数差时向负方向取整。所有图层与链接/停用蒙版的位置、样本、隐藏 RGB、层级、剪贴、锁及样式保持，画板外内容不会被删除或压平。扩展区域显示已有外部内容，其余透明。
- 文档当前/上次选区精确保留交集内的 u16 覆盖，裁到新画板，扩展部分为零。旧白色/反相的隐式默认覆盖不会漏到扩展区域；被裁掉的选区通过撤销恢复。每个选区最多复制 6400 万覆盖访问，逐行取消，使用共享预算。
- 改变画板之前冻结依赖旧画板的生成填充/渐变叠加尺寸，以及阴影高光的邻域采样边界。图层与样式保持可编辑；已有区域的颜色不会因画板尺寸变化而重新计算到不同参考。图层锁不阻止保留原样本的画布边界编辑。
- 工程 manifest v5 保存空间采样边界和样式参考；读取 v0–v4 时保留旧默认语义，第一次修改画布再冻结。旧版本元数据不能夹带 v5 引用，新版本往返与撤销有实际证据。
- 原生“变换”面板下提供画布宽高、固定锚点与应用按钮，使用同一注册命令。AI 有中英文说明、严格参数/返回、九个参数变体、中文提示与真实调用/整轮撤销回放。
