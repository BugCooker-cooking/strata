# M0 渲染验证（功能通过，性能待测）

## 目标与方法

wgpu 30.0.1 / Metal；8/16 位 P3 样本在线性化、预乘后上传 Rgba16Float 显示缓存；离屏输出 Rgba8UnormSrgb，原生输出 Bgra8UnormSrgb + DisplayP3 surface。像素读回与预期逐通道比较，允许 ±2 个 8 位码值。

## 结果

- 8 个强制真实 GPU 测试通过：图像/背景、透明图、零尺寸恢复、准备失败不改旧图/视图、Retina scale 数学、16 位源不变、透明边缘无色晕、候选不能跨 renderer 提交。
- 原生窗口显示示例照片；菜单放大、鼠标拖动、适合屏幕已在 UI 验证。
- 24MP 样例 4000×6000 已生成。**尚无 Release 持续交互数据，不宣称 60fps 达标。**

## 遇到的问题与 M1 结论

沙盒无法访问 GPU，本机授权验证通过。wgpu 30 的 surface 获取/呈现和错误作用域 API 与旧示例不同，按实际 API 实现；表面配置显式 P3。dirty-only 帧循环在静止时不持续提交，因此 HUD 的“1 fps”不能用来判断连续渲染性能。M0 不含 mipmap/分块；M1 必须加入分块合成、缓存预算与多层基准。
