## 已实现与验证

- `strata-pixels` 增加 `TileCoord`、`PixelValue`、`TiledPixels`；无新增依赖、无平台 API。
- 256×256 稀疏 RGBA 块，8/16 位分别存储；负坐标用欧几里得除法，覆盖 i64 像素端点。
- 克隆共享像素块，写入先准备副本再替换；未变化块继续共享。写相同值不复制、不报变化。
- 缺失块为全 RGBA 零；透明像素中非零 RGB 保留。只有最后一个非零样本清空后才回收块。
- 每实例最大块数限制，格式不符、块数超限和像素缓冲分配失败返回错误，已存状态不变。
- 10 个集成测试通过；测试先以缺少接口失败，再实现。覆盖负坐标/端点、双位深跨块、相邻 16 位值、隐藏 RGB、容量失败、COW、清空和确定性迭代。
- 本机 `make lint`、`STRATA_REQUIRE_GPU=1 make test` 通过：66 个 Rust 测试与 7 个 XCTest，0 失败；日志在 `build/m1a-step1-lint.log`、`build/m1a-step1-test.log`。中文错误提示的 Release 构建及 UI 复验另见 M0 实机表。

## 边界

此容器尚未替换 M0 的整图文档或单纹理渲染器。每像素写入接口仅用于存储原语，后续文档必须将其封装在命令执行器后面。

`referenced_bytes` 是当前实例引用的样本字节数，不是进程实际分配：共享块、旧快照、索引与 GPU 需要全局预算另行计量。块数上限、稀疏和 COW 不等于内存压力测试通过。索引/Arc 等小分配仍遵循标准分配器行为；M1b 的全局预留、淘汰和磁盘后备尚未实现。

清空像素时可扫描块判断是否全零，尚无批量写入或非零计数优化；接入解码/笔画前根据实测增加块级导入与编辑接口，不把逐像素调用当作最终高吞吐路径。
