# M2a AI 接口与原生面板进展

2026-11-04。属于 [v1 剩余开发](../plans/2026-11-04-v1-remaining.md)，M2a 正在验收，未发布预览版。

## 已实现

- `strata-ai` 可移植模块：从当前命令注册表派生分层目录、中英文搜索、完整说明；固定八个严格参数的元工具。尚未实现的命令不会出现在目录中。
- `ToolHost` 分离命令提交、画布、暂停/恢复与停止；Rust 决定下一步，原生宿主负责网络字节、文件选择与钥匙串。不把 API Key 传入 Rust 或写入配置、对话及日志。
- Anthropic Messages 与 OpenAI 兼容 Chat Completions 的请求编码、SSE 字节分片/UTF-8/多工具/用量解码；兼容非流式 JSON。缺失终止事件、截断、无效工具 JSON、重复 ID、超限与错误事件不能提交候选工具。
- 原生设置支持多个模型、地址与协议选择、只读模型列表、真实工具/视觉探测；Ollama/LM Studio 复用兼容接口。本地类型仅能连接回环地址；默认远程 HTTPS。用户指定 HTTP 接口后，新增独立明文选项与外发提示，凭据请求不跟随重定向。
- 默认“先问我”由 Rust 强制确认本轮普通编辑；删除/合并类修改单独展示参数。新建/打开/恢复需明确批准文档替换和新文档上下文；外部读写每次经原生选择器授予当前 AI 回合的能力，覆盖需另外确认。
- 回合绑定引擎会话、文档与提供方/完整地址/模型。隐藏图层名称不会经概览、直接查询或批查询自动发送；画布只渲染当前授权的可见合成与区域。原生画布上下文最长边最多 1024；只保留最近两张图，统计明确标注是有界取样。
- 每轮 50 个工具步骤、单请求 60 秒、活动执行 5 分钟（等待用户不计），网络最多重试两次；核心提交前重新检查可信截止时间。回合与请求 ID 隔离迟到回调，不允许旧轮次终止或恢复新轮次。
- 实时文字、提问/选项、参数与结果步骤卡、停止、来源历史/按回合撤销、画布操作权描边与提示；文件记录明确不随文档撤销恢复。对话按文档 UUID 在本机原子保存，配置文件不包含密钥。

## 验证与未完成项

确定性回放覆盖五类 M2a 任务：建层/不透明度、只读检查、滤色后授权导出、停止保留已提交步骤、提问后暂停用户操作。另覆盖重复/冲突、批量外部副作用拒绝、隐藏上下文、越权参数、文件撤销边界、替换上下文和迟到回调。

这些是程序构造的协议/行为夹具，**不冒充真实模型录制或真实修图效果**。真实模型任务尚待用户完成本机密钥配置。用户给出的兼容服务已用不带密钥的只读列表请求确认返回 HTTP 401；未发送图片或 API Key。

原生设置入口已通过界面观察。检查点 `bb32bad` 的完整本机回归为 **170 Rust + 27 XCTest，零失败**；含 19 项 AI 协议/回放与 4 项新增桥接验收，原生 Release 也已通过。28 个命令示例、可移植性、SwiftLint、格式和 Clippy 已通过。原生测试记录为 `build/M2aDerivedData/Logs/Test/Test-Strata-2026.11.04_22-08-54-+0800.xcresult`，Release 日志为 `build/m2a-release.log`。未把尚未运行的远程 CI、真实任务或 M2b 算作通过。

用户已在本机设置中录入密钥；兼容接口的工具连接测试通过并已保存连接。初次视觉探测未通过，当前降级为文字统计。用户补充明确授权将仓库 AI 示例文档的上下文发至指定的两种协议端点后，已在单个原生验收实例中实测 `gemini-3.8-flash-high`：目录发现与命令说明 2 步 → Rust 先问我确认 → 创建“草稿” → 透明度 50%，4 步完成；同一原生界面的整组撤销恢复为单一原始照片图层且无未保存修改。验收实例已退出，CUA 清点为 0 个运行中的 Strata。该结果仅覆盖一个模型的一项真实任务，不等同于两模型完整验收或视觉能力通过。

2026-11-05 接续：两种协议各跑完五类接口任务，初轮各有一次导出未执行，其余八项通过。原因是命令说明未讲明模型可以省略 resource、由宿主暂停并请求文件选择；补充元工具说明及适配后的参数 Schema 后，两种协议的导出定向复测均通过。视觉探测移除不必要的工具后两者均通过。原始失败与复测报告均保留，见 [M2b 集成记录](2026-11-m2b-local-editing-progress.md)；同一个 Gemini 模型经两种协议的结果不计作两个独立模型。
