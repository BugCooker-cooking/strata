# M2b 选区、蒙版、曝光与主体模型进展

2026-11-05，接续 [实施计划](../plans/2026-11-04-m2b-local-editing.md)。本地实现进入集成验收；完整 v0.1 的固定十张照片、两模型三轮质量指标和外部设备门槛尚未关闭。

## 已实现

- 稀疏、COW、单通道 u16 遮罩；与像素源共用预算、LRU、校验磁盘后备与历史配额。默认覆盖值与反相只改元数据，边界外固定零。
- 工程容器 v1 的单通道平面、旧 v0 RGBA 读取和原子事务迁移；文档选区、图层蒙版及曝光参数随工程与恢复检查点往返。未知版本、孤立平面、深度/通道/边界错误拒绝。
- 注册矩形/全选/取消/反选、白黑/选区蒙版、停用/反相/移除蒙版、曝光调整层与参数、亮度直方图、主体选择。矩形支持相加/相减/交叉；暂停用户框选进入回合历史并在恢复信息中显示区域。
- 线性光曝光、蒙版与不透明度插值；源样本不改写。CPU 合成和 GPU 显示缓存的指纹包含调整参数、蒙版布局与相关块版本。原有无蒙版单照片快速路径保留。
- 原生矩形拖动/Esc 取消、基础蚂蚁线（支持减弱动态效果）、蒙版面板、曝光数值/连续预览、亮度直方图；选区/曝光交互只提交一条历史。主体模型面板展示下载、许可、错误与取消；所有文档修改仍走同一命令总线。
- `strata-ml` 使用固定 U²-Net-P ONNX 模型；本机 CPU、Core ML 推理与正常退出均已实测。模型下载由用户确认，固定 SHA-256、大小限制、临时文件与完成校验；离线与取消不提交选区。
- 模型是显著前景分割，不是人物身份识别。多组件/低置信/异常前景比例返回未提交的询问指引；用户可用矩形缩小范围或明确确认。尚需困难照片质量验证，不能仅凭组件数承诺识别所有多人场景。

## 已取得的证据

- 最新正常本机权限下的低并发完整回归：193 Rust 测试通过，原生 XCTest 29 项中 28 通过、1 个明确 opt-in 的网络测试跳过。沙盒内系统 HEIC 编码和 Metal 不可用的失败另行保留，不代替本机通过记录。
- 40 个注册命令的隔离示例已通过；主体示例注入明确标注的确定性遮罩，不伪装成真实模型质量。
- 8/16 位曝光与独立解析 sRGB 数值对照、遮罩布尔运算、缓存失效、失败原子性、工程/检查点往返、暂停用户框选及取消长任务有核心测试。
- 真实 ONNX 主体命令、曝光、撤销、保存重开：已显式运行默认忽略的资产测试，3.25 秒通过；每个原始 RGBA 块逐样本一致。该测试发现并修复源图无 ICC 时配置文件显示名称的往返变化。
- [CPU 报告](data/2026-11-05-m2b-subject-cpu.json)：320×320 模型，单前景组件、约 98.99% 高置信取样；[Core ML 报告](data/2026-11-05-m2b-subject-coreml.json)：同样例可用，推理约 224 ms，首次加载/编译约 3.60 s。统计中的预算保留量不等同于进程 RSS。
- M2a 两种协议的 8 项非导出真实任务通过；补充宿主文件选择说明后，两种协议导出复测均通过。视觉探测移除无关工具后两者通过，见 [初轮（保留两个导出失败）](data/2026-11-05-m2a-live-initial.json) 和 [定向复测](data/2026-11-05-m2a-live-export-rerun.json)。目前这些任务使用同一个 Gemini 模型，经两种协议验证；不等同于 v0.1 要求的两个独立模型质量评测。
- 完整局部修图实测：Gemini（OpenAI 兼容协议）与 Claude Sonnet 4.6（Anthropic）在 8/16 位样例上均完成主体选择、曝光 +0.5、暂停、用户矩形修正、蒙版曝光和保存重开；目标采样点亮度比约 1.146，两个保护采样点最大通道误差 0，撤销/重做与源图层样本保持。指标见 [授权的本地实测](data/2026-11-05-m2b-live-local-repair.json)。
- 同一 Release 场景的曝光连续预览 p95 从 CPU 合成约 207.04 ms 降到 GPU 底图/蒙版纹理路径约 4.51 ms（目标 33.33 ms）；数据见 [before](data/2026-11-05-m2b-exposure-preview-before.json) 与 [after](data/2026-11-05-m2b-exposure-preview-after.json)。强制真实 Metal 的 14 项渲染测试全部通过。

## 运行库与许可

模型 SHA-256：`309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`，4.6 MB，来自 [rembg 固定发布](https://github.com/danielgatis/rembg/releases/tag/v0.0.0)，上游 [U²-Net Apache-2.0 许可](https://github.com/xuebinqin/U-2-Net/blob/master/LICENSE)，ONNX 转换 MIT。

Microsoft 原始 ONNX Runtime 1.22.0 在推理成功后复现 macOS 退出崩溃（[上游问题](https://github.com/microsoft/onnxruntime/issues/24579)）。已改用 ort 维护者带日志互斥修复的固定分发，归档与静态库分别校验，构建为应用内库后签名并记录最终哈希。源许可、第三方声明和归档指纹随应用打包，见 [NOTICE](../../vendor/onnxruntime/NOTICE.md)。未用忽略异常或强制退出掩盖该失败。
