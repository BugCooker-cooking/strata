# M7 整层像素变换与实际像素视图检查点

2026-11-06，仅本机验证。本页覆盖整层像素/链接蒙版的数值与四角变换；[完整 M7](../plans/2026-11-05-m7-geometry-text.md)、完整 Photoshop 编辑及最终 AI 入口审计仍在推进。

## 已实现路径

- `transform.apply` 使用真实分块单应采样和统一事务；必填 `scope=whole_layer`，可选 components / affine / matrix / corners。数值入口支持画布轴心、平移、负比例翻转、缩放、旋转、双轴斜切；四角入口支持凸四边形透视/扭曲，明确坐标与系数顺序。
- 使用不可变源和 COW 输出，不裁掉画板外内容。全层变换保留文档选区和样式，链接 u16 蒙版同步变换且保留启用状态。整数移动仅更新位置，保持原像素/蒙版块；整数轴置换精确映射像素中心，±1e12 范围内的大坐标回归保护 8/16 位码值和透明区 RGB。一般变换的局部存储以目标逻辑边界重定基，图层 X/Y 报告该原点。
- 最近邻保留采样码；双线性对分数中心使用实际工作 ICC、预乘线性 P3。输出限 6400 万像素访问；RGB/蒙版各有最多 8 块缓存和 4096 次解码限制，逐行取消与全局内存预算。失败、取消、奇异/视界穿越、空层和锁定目标均保持原文档与历史。
- `layer.pixel_bounds` 是只读可取消查询，包含原始透明区隐藏 RGB 和画布偏移。隐藏层/隐藏祖先和非像素类型拒绝，空层返回 null。AI 可先读取实际边界再选择轴心/源四角。
- 原生同一窗口新增“变换”面板，共用单一显示预览槽：预览不更改保存/历史，应用提交一次候选，取消恢复。输入框在应用期间锁定，取消独立可用。滤镜面板直接观察预览状态，修复忙碌时取消按钮未及时启用的问题。
- `view.actual_size` 将物理像素缩放绝对设为 1.0，保留视图中心，不改变文档/历史；原生实际像素按钮和 AI 使用相同命令。
