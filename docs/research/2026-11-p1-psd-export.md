# P1 分层 PSD 导出

2026-11-19。打开一个工程，在“文件 → 导出分层 PSD…”中选择目标。得到的副本可在支持该格式的应用里继续编辑。也可以让 AI “导出分层 PSD，保留图层和蒙版”。两条入口调用 `file.export_psd`。宿主为所选路径提供单次写入授权，模型可省略资源字段请求文件选择器。[命令目录与可执行示例](../commands/reference.md)

| 内容 | 输出行为 |
|---|---|
| 画板和像素 | 原始画板尺寸、8/16 位 RGB、工作 ICC、DPI、Unicode 层名。写入像素层的原始通道，包含隐藏层、零透明度像素的 RGB 和画板外的非零样本。图层位置以导出画板的左上角为原点。 |
| 结构和属性 | 保留组和子层、可见性、剪贴、支持的混合模式、图层与填充不透明度、锁定和颜色标签。PSD 的不透明度字段取最近的 8 位值。 |
| 蒙版与调整 | 保存栅格蒙版的有效采样值、位移及启用状态。16 位软蒙版保留 16 位值。8 位文档中的软蒙版如需更高精度，导出提示先将文档副本转换为 16 位。反相和曝光调整可重编辑，PSD 曝光参数使用单精度浮点。 |
| 合成预览 | 写入当前画板的合成和透明度。外部应用重新混合图层时，编码 RGB 与 Strata 线性光混合的差异仍可能影响外观。[已测差异](2026-11-p1-psd-import.md) |
| 文件与历史 | 导出使用准备时的固定快照。同一文档随后继续编辑时，副本反映该快照。切换文档、取消请求或目标被替换会使待发布副本失效。先校验 PSD 目录，并对暂存文件逐字节读回，之后按授权原子发布。导出保留当前工程路径、修改状态和撤销历史。 |

后续支持开放与闭合的保存路径、切线手柄和 Unicode 名称。[工作路径交接](2026-11-p1-psd-work-paths.md)

每边上限 30,000 像素，文件受 512 MiB 和当前共享内存预算限制。文字、生成填充、图层样式、智能对象和其他调整类型待扩展，遇到无法保留的图层时会指出层名。导出范围是图层和画板。选区与参考线保存在 `.strata` 工程中。Photoshop 桌面版交叉验收仍待完成。

## 本机互操作验证

使用 psd-tools 1.10.8 独立打开 Strata 输出的两份文件。8 位样例包含两个像素层，其中一层隐藏，另一层含半透明像素。16 位样例保留五层，含组、中文及非 BMP 字符的层名、负坐标、软蒙版、曝光和反相。独立阅读器识别了两种调整，嵌入的 ICC 与同画板 PNG 完全相同，两份文件的 DPI 分别为 72 和 300。逐码解压五层样例，透明度为零的像素保留 RGB 12345、0、45678，蒙版四个取样点分别为 0、65535、10001、40003。读取合成预览与同一画板的 Strata PNG 比对，16 位样例转换成 8 位显示值后各通道相同。8 位半透明样例的 RGB 通道最大差值为 1，alpha 精确相同。原层样本和 16 位蒙版另用完整精度的重开测试核对。[核心往返与失败测试](../../crates/strata-core/tests/psd_export.rs)

macOS XCTest 运行 132 项，131 项通过，1 项联网模型测试按配置跳过。原生导出处理写出副本，Apple ImageIO 读到正确的画板尺寸，再经 Strata 打开确认图层仍可编辑。单个 arm64 Release 窗口打开本轮写出的 4 × 3、16 位五层文件，真实 Metal 画布完成 161 次显示回调，应用已退出。此项用于确认显示路径。[原生验收用例](../../apps/macos/StrataTests/PSDImportTests.swift)

AI 直接执行模式的本机回放覆盖取消和批准两条路径。取消后没有输出文件，批准后由当前回合的文件授权写入，副本可重新打开，执行记录包含一次外部写入。所有 149 条命令的 224 个隔离示例通过，94 个 P0 综合条目通过入口审计。当前 AI 功能映射为 104/265，PSD 导入和导出均按部分实现跟踪。[AI 回放测试](../../crates/strata-ai/tests/replay.rs) · [功能清单](../plans/photoshop-feature-coverage.md)
