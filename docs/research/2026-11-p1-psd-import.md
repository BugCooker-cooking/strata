# P1 分层 PSD 导入

2026-11-19。通过 macOS 的“文件 → 打开”选择 PSD，再通过“另存为”保存为 Strata 工程。AI 使用同一条 `file.open` 命令。可用“打开我选择的分层 PSD，保留图层和蒙版”或“Open my layered PSD”发现入口，文件选择器为当前回合授予读取权限。打开会开始新的文档历史，替换有修改的文档需要明确允许放弃修改。打开后的编辑可撤销，首次保存会选择工程目标。

| PSD 内容 | 本次支持范围 |
|---|---|
| 文档 | PSD v1 的 8/16 位 RGB，保留嵌入的工作 RGB ICC。分辨率要求水平与垂直相同，读入后按 Strata 的整数 DPI 表示。无图层记录时读取三通道 RGB 合成图。 |
| 像素与组织 | 像素源样本、透明度、画板外内容、层名、顺序、偏移、可见性、图层组、剪贴关系、混合模式、图层及填充不透明度。显示使用 Strata 的色彩与混合引擎。 |
| 蒙版与调整 | 基本栅格蒙版保留范围、黑白背景、灰阶覆盖和启用状态。反相与曝光可继续编辑，曝光要求偏移为 0、伽马为 1。导入后的栅格蒙版随所属图层移动。 |
| 编码与容量 | 原始通道、逐行 PackBits、ZIP 和带预测的 ZIP。输入上限 512 MiB，逐层解码计入共享内存预算，沿用画板、图层数量及工程容量限制。 |

遇到文字、矢量蒙版、智能对象、图层样式、其余调整类型或无法表示的混合选项时，打开操作报错，已有编辑和历史保留。额外文档通道、PSB、CMYK 和浮点样本仍待支持。分层副本输出见[PSD 导出记录](2026-11-p1-psd-export.md)。

## 本机验证

原始 16 位样例包含一个底层、图层组、带软蒙版的偏移像素层及隐藏的曝光和反相调整层。分别打开两种调整层的可见性会改变合成，撤销后恢复原始合成。核心测试逐码检查完全透明像素中的 RGB、蒙版边缘及 16 位透明度，并验证重命名、撤销、重做、工程保存与重开。另有 8/16 位平面 RGB 和 ICC 样例、当前 AI 回合文件授权以及不兼容文件和截断文件保留现有文档的回归。[样例生成器](../../crates/strata-core/tests/fixtures/psd/make_fixture.py) · [核心测试](../../crates/strata-core/tests/psd_import.rs)

使用 psd-tools 的公开文件在本机通过实际命令检验。无层的 `0layers.psd`、带西里尔层名的 `2layers.psd`、三层的 `16bit5x5.psd` 和保留空组的 `empty-group.psd` 成功打开。另六个含文字、矢量填充或高级蒙版的样例返回兼容性错误。[第三方样例目录](https://github.com/psd-tools/psd-tools/tree/main/tests/psd_files) · [Adobe 格式规范](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)

将当前工程的像素源与 Pillow 独立解码结果逐通道比对，`2layers.psd` 两层共 37,860 个 RGBA 通道值全部相同。该文件按编码 RGB 混合，Strata 按线性光混合。101 × 55 的画板中，导出与内嵌预览有 921 个像素不同，8 位 RGB 单通道最大差值为 60。以原层样本独立计算线性光混合，结果逐像素等于 Strata 导出。另三份成功导入的公开样例在 8 位 RGB 对照中与其合成预览相同。保留 Photoshop 混合空间仍是兼容性缺口。

在本机 Apple Silicon 上，强制真实 Metal 的 Rust 工作区回归通过 637 项，按配置跳过 1 项 ONNX 模型用例。macOS XCTest 通过 130 项，跳过 1 项联网模型用例。原生用例经工作区打开五层测试文件，读取图层层级、蒙版和曝光值。arm64 Release 单窗口另行打开同一文件，在 4 × 3、16 位、五层的文档上产生 69 次显示回调，应用随后退出，样例 SHA-256 保持一致。该记录仅用于核实文件打开和显示。[原生测试](../../apps/macos/StrataTests/PSDImportTests.swift)

最终版的 PSD 核心回归 4 项、参数示例与提示词发现、编解码边界测试均通过。全部 148 条命令的 223 个隔离示例执行成功，P0 的 94 项映射全部通过，PSD 导入保留“部分实现”。Rust 格式、Clippy、SwiftLint、可移植性、1,167 条界面文案及功能清单一致性检查通过。
