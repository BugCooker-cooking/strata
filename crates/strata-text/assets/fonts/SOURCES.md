# Bundled typography fonts

Unmodified original font binaries, distributed under the accompanying SIL Open Font License 1.1 files. Fonts are data, not local system font paths or an AI file capability. Their fixed bytes ship with the portable text renderer so saved documents do not silently substitute platform fonts.
